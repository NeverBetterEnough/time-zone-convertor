如何使用

  1. 点击 Chrome 工具栏的拼图图标，将本插件固定到工具栏。
  2. 在插件弹窗中搜索城市或地区，选择时区并保存。
  3. 保持“自动切换”开启，现有网页和新打开的网页会自动应用。
  4. 网页如缓存了旧时间，请先保存编辑内容，再点击“应用并刷新此页”。
  5. 关闭插件内开关即可恢复系统时区。

状态与范围

  • 默认启用，默认时区为 Asia/Shanghai；设置保存在本机，重启后继续使用。
  • Chrome 的调试提示条由浏览器显示。关闭提示条或打开开发者工具可能断开连接，需要手动重新应用。
  • 支持普通 HTTP / HTTPS 页面。Chrome 内部页、扩展页、商店页面和休眠标签会跳过；休眠标签唤醒后再处理。
  • 跨进程 iframe 会自动连接。Worker 在支持的目标上设置覆盖，其他目标会检查继承的时区；未确认覆盖会显示警告。

检测结果应该如何理解

偏移以 UTC 为基准，例如上海是 UTC+08:00。1 月和 7 月偏移不同通常意味着该地区使用夏令时，插件交给浏览器原生时区规则处理。

修改时区不会改变时间戳、系统时钟、IP、定位或账号里的时区设置。网页显式指定某个时区、固定输出 UTC 或由服务器生成时间时，显示内容可能保持原样。

插件与网页启动之间存在时序窗口，无法保证首次访问时赶在每一段网页脚本之前。已启动的 Service Worker / Shared Worker 是否可被关联取决于 Chrome 的目标关系，不能保证所有后台环境都覆盖。

扩展不上传浏览数据，不请求外部服务。为自动管理标签页，使用 debugger、storage、tabs 和 alarms 权限。实际调试状态仅存于当前浏览器会话。
